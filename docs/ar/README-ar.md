# كيكـ — دليل البدء السريع

حزمة كيكـ تحوّل تطبيق الويب الأصلي إلى:

- **تطبيق سطح المكتب** (Windows / macOS / Linux): يسجّل **صوت الجهاز + الميكروفون** بدون بوت ينضم للاجتماع، مع تفريغ مباشر، وحفظ البيانات كملفات على جهازك، وتشفير مفاتيح الذكاء الاصطناعي.
- **إضافة المتصفح** (Chrome / Edge / Brave): تكتشف اجتماعات Google Meet وZoom وTeams على الويب، تسجّل **صوت تبويب الاجتماع + الميكروفون**، وتتحكم في تطبيق سطح المكتب.
- **وحدة الذكاء الاصطناعي**: تستخدم الطبقات **المجانية** من Groq وGoogle Gemini للتفريغ والتحليل والبحث، مع اختيار تلقائي للمزود والتحويل للآخر عند الضغط أو الخطأ.

لا يوجد خادم أو حساب لكيكـ؛ كل شيء يعمل على جهازك بمفاتيحك.

## ١. احصل على مفتاح مجاني

- **Groq** (مُستحسن أولاً): من <https://console.groq.com/keys> ← Create API key. يُستخدم لتفريغ الصوت بـ Whisper ولتحليل الاجتماعات القصيرة بسرعة.
- **Gemini**: من <https://aistudio.google.com/apikey> ← Create API key. يُستخدم للاجتماعات الطويلة ولتمييز المتحدثين.

مفتاح واحد يكفي، والاثنان أفضل. التفاصيل والحدود في [02-free-api-keys.md](../02-free-api-keys.md).

## ٢. تشغيل تطبيق سطح المكتب

يحتاج Node.js 20 أو أحدث:

```bash
cd desktop
npm install
npm start          # تشغيل
npm run dist       # بناء ملف تثبيت لنظامك داخل desktop/dist
```

ثم: **الإعدادات ← الذكاء الاصطناعي** ← الصق المفتاح ← **حفظ الإعدادات** (يُختبر تلقائياً).

للتسجيل: **الاجتماعات ← + ← التسجيل من تطبيق سطح المكتب** ← اختر *صوت الاجتماع* و*الميكروفون* ← فعّل خانة الموافقة ← **ابدأ التسجيل**.
استخدم سماعات رأس لتجنب الصدى.

**على macOS**: سيُطلب إذن "تسجيل الشاشة والصوت" عند أول تسجيل لصوت الجهاز (لا تُحفظ صورة الشاشة). إن لم يصل صوت الاجتماع، ثبّت BlackHole المجاني واختره كـ "جهاز إدخال" — التفاصيل في [03-desktop-app.md](../03-desktop-app.md).

## ٣. تثبيت الإضافة

١. افتح `chrome://extensions` ٢. فعّل **Developer mode** ٣. اضغط **Load unpacked** واختر مجلد `extension`.
يفتح كيكـ في تبويب؛ أضف مفتاحك من الإعدادات.

أثناء اجتماع على الويب: اضغط أيقونة كيكـ **وأنت على تبويب الاجتماع** ← فعّل الموافقة ← **سجّل هذا التبويب + الميكروفون** ← اضغط **ابدأ التسجيل** في تبويب كيكـ.

## ٤. ربط الإضافة بتطبيق سطح المكتب

تطبيق سطح المكتب ← **التكاملات** ← انسخ **كود الاقتران** ← افتح نافذة الإضافة ← الصقه ← **اقتران**.
بعدها يمكنك بدء وإيقاف التسجيل في تطبيق سطح المكتب من نافذة الإضافة (يسجّل كل صوت الجهاز، ومنها تطبيقات Zoom وTeams لسطح المكتب).

## ٥. رفع ملف صوتي

**الاجتماعات ← + ← رفع ملف صوتي** ← اختر الملف ← **تفريغ تلقائي** ← راجع النص ← **حفظ ومعالجة**.
الملفات الكبيرة تُقسَّم تلقائياً إلى مقاطع ٥ دقائق.

## ملاحظات مهمة

- الطبقات المجانية لها حدود وتتغير؛ كيكـ يعيد المحاولة ويتحول للمزود الآخر ويخبرك عند تجاوز الحد.
- البيانات المرسلة إلى Groq أو Gemini تخضع لشروطهما؛ **الطبقة المجانية من Gemini قد تستخدم المحتوى لتحسين خدمات Google**. لا ترسل اجتماعات سرية — راجع [07-privacy-security.md](../07-privacy-security.md).
- أبلغ المشاركين دائماً قبل التسجيل؛ القوانين تختلف حسب الدولة.
